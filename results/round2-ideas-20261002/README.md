# 第二轮：三个 training-free 4D 编辑方向的 GPU 初测

**结论：三个方案都已实现并完成 GPU 测试；没有一个达到本轮预先规定的继续标准。** U 有有限的受控信号，但尚未迁移到独立编辑目标；G/T 当前版本不值得继续包装为新方法。不是训练，也没有重跑 ActionMesh 生成器。

## 三个 idea 与结果

| 方案 | 可检验机制 | 主要结果 | 决定 |
|---|---|---|---|
| U：编辑方向的反事实效用 | 在独立邻点上验证这次编辑的响应，选择局部/全局搬运 | 受控混合动作比普通三维残差筛选 EPE 低 4.48%；3/4 对象改善。但未到预定 10%，ActionBench clean/noisy 分别差 1.61%/9.11% | 仅保留为探索信号；未通过继续标准 |
| G：方向相关几何不确定性 | 由旋转信息矩阵估计编辑方向敏感度 | 比标量对照只低 0.085%；12 个对象×采样单元中，编辑区弱几何支持点数全为 0 | 当前必要性无证据，不继续 |
| T：时间路径分歧 | 比较直接搬运和独立中间帧路径的编辑结果 | 比方向无关的时间矩阵对照误差高 2.48%，比空间分割对照高 4.15% | 当前版本淘汰 |

上表是描述性比较，不是显著性检验。U 与普通残差对照使用完全相同的候选、拟合点和独立验证点；G/T 比较相同 50% 回退预算，另保留 25%/75% 结果。全局噪声场景下，直接全局方法明显更好，三个选择器都没有解决这个边界。

## 独立目标任务

从官方 [ActionBench](https://huggingface.co/datasets/facebook/actionbench) 固定版本中，在看结果前选择按 UID 排序的前四个对象。输入为已有动画点轨迹和第一帧法线方向的局部凸起；标准答案是同一幅度沿后续官方法线移动。**后续法线仅用于算误差，不进入算法。**

这测试的是给定 4D 资产上的几何编辑传播，既不是官方 ActionBench 视频重建排行榜，也不是文字语义编辑、整幅图像编辑或原生扩散 latent steering。没有第二个生成模型的验证。

EPE 除以完整第一帧包围盒对角线，越小越好：

| 方法 | ActionBench clean | ActionBench 加噪声 |
|---|---:|---:|
| 直接局部搬运 | 0.0006358 | 0.0009456 |
| 普通三维残差筛选 | 0.0006397 | 0.0009547 |
| U | 0.0006500 | 0.0010416 |
| G（50%回退） | 0.0025060 | 0.0028948 |
| T（50%回退） | 0.0024029 | 0.0026762 |
| 直接全局搬运 | 0.0052565 | 0.0052600 |
| 每帧 PCA 法线简单对照 | 0.0086007 | 0.0086992 |

U 在部分自定义响应指标上变好，但真实目标 EPE 变差；这直接反驳“优化自己的能量就等于编辑更正确”。简单局部搬运在这四个对象上已很强。不能把置信度、拟合残差或路径一致性直接当作干预收益。

## 测试范围与资源

- 4 个已有 ActionMesh 资产：袋鼠、章鱼、蘑菇、熊猫；3 个采样种子；5 个编辑方向；5 个有解析目标的动作控制和 1 个原轨迹诊断，共 360 组合。
- 4 个 ActionBench 对象；3 种采样；clean/noisy 两种条件，共 24 组合。合计 **384 个唯一组合，324 个有目标误差、60 个仅诊断**；不是 384 个独立对象。
- 每个对象采样 1024 个材料点：512 拟合/编辑点，256 独立决策支持点，256 独立报告支持点；局部32邻点，验证/报告各8邻点。
- RTX 2080 Ti 22528 MiB；两次有效运行合计 **103.51 秒**（不含网络传输和启动）；监测到物理显存峰值 **2763 MiB（约2.70 GiB）**，PyTorch 峰值 allocated 2.09 GiB / reserved 2.50 GiB，无 OOM。这是编辑后处理开销，不代表生成器全流程显存。
- 无模型训练、参数更新或本轮生成器前向。
- 所有输出有限，首帧编辑和未编辑区域保持精确；无噪声刚体对照的最差搬运 EPE 为 5.09e-9；world 不随转动本来就是负对照，不纳入此 sanity。

## 执行问题与复现

国内 hf-mirror 连接超时，改从本地取得同一固定版本的四个官方文件。大文件上传过慢，改传完全相同预定点的无损包；12 个对象×采样条件已逐元素验证，完整原始文件保留在本地 data/actionbench-round2。没有降低精度或更换样本。

首次启动脚本把已有生成资产的目录错写为 outputs，实际为 publication，四个资产 FileNotFoundError。首次仍完成了24个 ActionBench 测试；保留其日志与结果，仅修正路径并补跑缺失的360个组合，成功结果没有重跑。merged results 用 source_run 标记两次来源，resolved_failures 保留原错误。

运行前修正了“打乱方向”对照会同时打乱零编辑掩码的问题；目前只在活跃点间打乱单位方向，幅度和掩码保持不变。统一世界轴编辑的这个消融自然为恒等，仅 PCA/normal 方向的消融有区分力。时间路径与空间分割实际附加拟合数分别42/45，不声称严格等计算量。

## 与文献和 skill 状态的关系

沿用了 `research-autopilot` 的机制、反例、强对照和负面证据记录流程。这是用户明确要求的探索性实现；没有伪造 Natural Gate 0、IPCG 或 Gate A 通过，研究状态仍是 repair_evidence / not_ready。

[Sumner & Popović 2004](https://people.csail.mit.edu/sumner/research/deftransfer/)、[Fast4DMesh](https://arxiv.org/html/2605.19786v1) 已覆盖变形转移/局部 Procrustes 部分；[旋转平均与循环一致性](https://arxiv.org/html/2102.05454v1) 覆盖循环筛选的一般思想。旋转估计协方差也是既有工具。各 scout 文档保留原查询与阅读深度；这不是完整新颖性检索。

当前最有价值的结论是：先验证某个具体编辑的错误及干预收益，再决定是否需要 steering。U 的小幅受控优势不足以支持 ICML 方法主张；G 的假设场景在当前原始资产上没有出现；T 的复杂性被简单对照否定。不会把这轮包装成三个成功的新方法。
