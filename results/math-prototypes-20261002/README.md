# 三个数学方法的代码与首轮测试

2026-10-02。已实现三套 NumPy 原型、运行全部测试，并在原有 RTX2080Ti22GiB 服务器上完成两个真实冻结 ActionMesh 解码器测试。没有训练、下载新模型或修改已有实验。

**当前结论：代码与局部 GPU 控制接口可运行，尚未建立新方法优于强基线的证据。**

## 实现与复现

代码位于仓库的 `actionmesh/research_math/`：

| 模块 | 内容 |
|---|---|
| correlated.py | Woodbury 低秩相关误差逆、信赖域与逐组真实观测约束、拒绝后保留零修正 |
| controllability.py | 共同输出度量下的可达空间、有界/无界编辑求解、模型与输出空间比较 |
| contact_events.py | 接触事件匹配、增删/替换、端点轨迹修复、严格单调重定时基线 |
| native_probe.py | 原生解码器缓存复现、有限差分 Jacobian、实际重新解码、约束检查、GPU 记录 |
| run_controls.py | 一条命令运行三组构造控制，输出 JSON 和代码哈希 |

从仓库根目录运行：

```bash
cd actionmesh
python3 -m unittest discover -s research_math/tests -v
python3 -m research_math.run_controls --output ../results/math-controls-new --seed 42
```

CPU 原型只依赖 NumPy。输出目录必须是新的。原生 GPU 命令在代码目录 README 和每个 GPU 输出的 `command.json` 中；复用服务器已有环境、权重和缓存，无需重新下载。

## 正确性与兼容性

- 新原型41项测试：本地 Python3.14.6/NumPy2.5.1 与服务器 Python3.12.13/NumPy1.26.4 均通过。不是82个独立测试。
- 另5项已有时间解码/恢复接口回归测试通过。
- 一个新发现的基线问题已修复：微小位移加权可能让重定时错过精确接触解。新增回归先复现失败，再验证词典序“观测误差优先、位移次之”修复；独立复核通过。
- 保留修改前日志、原始数值控制和修复后的最终测试。`controls-final/` 为最终代码的数值结果，`controls/` 与远端 `remote-controls-v1/` 为修复前留档。六个既有接触示例的结果未改变，新增回归单独覆盖被修复问题。

## GPU 实测

使用此前已成功生成的 mannequin 和 bat，seed42。保留全部16个上下文帧，测量输出帧1/8/15上的24个固定原始查询点。六个控制参数只改变查询XYZ，法向与权重冻结。**这是稀疏局部运动控制实验，不是完整网格重建/语义编辑效果评测。**

| 检查 | mannequin | bat |
|---|---:|---:|
| 总运行时间 |18.47秒|18.37秒|
| 整卡采样显存峰值 |2779MiB|2779MiB|
| 相对已有原生输出的RMS/D |4.30e-8|4.45e-8|
| 独立缓存头重放最大误差 |0|0|
| 两个差分步长的Jacobian相对差异 |0.00443|0.00466|
| 通过真实解码后约束检查的非零编辑 |3/3|3/3|

D 是原始anchor包围盒对角线。显存是本次局部探针的数据，不能外推为完整生成或十个并行模型的显存需求。每次只运行一个GPU进程，实际耗时远低于预设600秒上限。

目标是让末帧一半采样点的质心沿三个轴分别移动0.002D，同时保持中间帧质心。经过查询位移限幅和真实解码回溯，构造目标的误差下降10.74%–29.21%，六次均在预设约束内。这些百分比**不是重建精度或官方4D指标提升**。直接修改采样输出点的参考解可几乎精确达到目标，尚未显示模型内部控制更有必要；该参考解也不保证完整网格或语义动作有效。

A 的CUDA低秩矩阵运算使用实测解码器Jacobian、构造的右端向量，与CPU结果差异约1.8e-15。没有把它称作真实生成视角可靠性验证。C 本轮没有真实多物体GPU生成测试。

## 三条方向的结果

**A：机制有条件成立。** 在构造的共享偏差场景中，相关权重的参数误差0.413，普通等权0.987，简单按数量降权0.813。但在生成先验本来正确的控制中，相关权重误差0.283，等权0.0086，反而较差；偏差方向设错和自渲染控制也保留了不利结果。需要真实来源链、真实观测和独立留出目标，才能判断何时启用；当前不支持自然4D有效性或置信度校准结论。

**B：接口与诊断原型可用。** 正确处理输出度量、可逆latent重参数化、不可达方向、有限步长、零空间和非线性约束。原生GPU探针能产生保持指定局部约束的小幅变化，但没有胜过直接输出空间基线，也不是身份/形状编辑能力的证明。

**C：当前简单问题不需要额外离散层。** 缺失、错误对象及错误顺序的构造案例可以修复，纯时间偏移也可由重定时解决；预算不足被正确报告。给直接连续求解器同样的信息后，全部示例结果与事件封装相同，未观察到离散层收益。
